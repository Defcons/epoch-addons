# QuestRewardIcons

A small World of Warcraft 3.3.5 (Project Epoch) addon that puts **value icons on quest-reward
choices**, so you always pick the most valuable item.

## Features

- Shows a **gold** (vendor value) or **disenchant** icon on each quest-reward choice item.
- Highlights the **best pick**.

## Install

Drop the `QuestRewardIcons` folder into your `Interface/AddOns/` directory.
