# TitanPerformance (v1.0)

Originally by Titan Development Team. Modified for **WoW 3.3.5a (Ascension/Epoch)** by Defcon — uses independent version history.

## Features

- Displays FPS and memory/garbage collection information in Titan Panel
- Memory monitor integration

## Requirements

- **Titan Panel** must be installed

## Compatibility

- **Server:** Ascension / Epoch private server
- **Interface:** 30300 (WoW 3.3.5a)
- **Lua:** 5.1
